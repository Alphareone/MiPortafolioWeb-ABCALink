Globo Terráqueo 3D

Aplicación web interactiva que renderiza un globo terráqueo en 3D en el navegador. Permite seleccionar países mediante clic, buscador o etiquetas flotantes para consultar datos clave en tiempo real, combinando de forma eficiente APIs externas con un sólido respaldo local. Diseñado para ser ligero, responsivo y de carga instantánea.

05 / REAL-TIME LOGIC

Jiren Sushi App

Plataforma interactiva de una sola página (SPA) orientada a la optimización de canales comerciales para gastronomía local. Resuelve la inconsistencia en los desfases de atención mediante un algoritmo de control en tiempo real anclado a la zona horaria continental de Chile, automatizando el flujo de conversión mediante enrutamiento directo y plantillas dinámicas hacia la API de WhatsApp.
